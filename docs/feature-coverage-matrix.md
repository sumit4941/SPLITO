## Enhancements chosen by SPLITO

- One generalized context model keeps group, direct, and personal journals under
  identical currency and authorization boundaries.
- Deterministic expense-level bilateral matching is persisted separately from
  optional simplification.
- Durable Oracle outbox/jobs avoid a mandatory Redis dependency.
- Runtime/migration schema separation and mandatory table prefix validation are
  stricter than a typical development setup.

## Explicit non-claims

No exact parity is claimed for undocumented reference behavior. Static pages,
schema presence, unit tests, and a configured adapter boundary do not prove a
complete feature. Local `developmentOtp` and in-memory invitation capture are
not carrier-delivery evidence; production configuration fails closed unless the
Twilio adapter is fully configured. V006 is applied and validated locally, and
the complete verification pipeline, live Oracle smoke, reconciliation, and
browser suite pass. Live carrier SMS, payments, OCR, email, bank feeds,
production backup/restore, ASVS verification, and measured performance remain
unavailable until their stated evidence and credentials exist.
